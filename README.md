## Featured projects

### ADT Leveraged Buyout & Downside Analysis

A five-year hypothetical leveraged acquisition model linking operating forecasts, cash flow, debt repayment, and sponsor returns. Includes base and downside scenarios, exit valuation sensitivities, and an investment memo.

**Finding:** Modeled equity IRR is 18.6% in the base case and −9.8% in the downside, supporting a pass at the modeled terms against a 20% return target.

**Tools:** Excel · Financial modeling · Scenario and sensitivity analysis

[Interactive analysis](https://tristancarel.github.io/TristanCarel/#projects) · [Project overview](PROJECT-OVERVIEW.md) · [Excel model](ADT-Downside-Underwriting.xlsx) · [Investment memo](ADT-Investment-Memo.pdf)

### Distributor Financial Analysis Dashboard

A financial research pipeline and interactive dashboard comparing Grainger, MSC Industrial, and WESCO across FY2021–2025. Connects 120 sourced financial observations in SQLite with analysis of profitability, cash conversion, and working capital.

**Research focus:** Investigate changes behind the numbers, including MSC's receivables-sale program and the working-capital demands of WESCO's growth, using annual filings to explain screening results.

**Tools:** Python · SQL / SQLite · pandas · Streamlit · Plotly

[Live dashboard](https://tristan-distributor-research.streamlit.app/) · [Source code and documentation](https://github.com/TristanCarel/distributor-financial-analysis-dashboard) · [Portfolio case study](https://tristancarel.github.io/TristanCarel/#sql-project)

## How I approach analysis

Start with sourced data and explicit assumptions. Connect financial results to operating drivers, investigate unusual changes, and communicate the conclusion alongside its limitations.

<summary>Project scope and methods</summary>

The ADT analysis is an educational hypothetical transaction. Model-defined EBITDA differs from company-reported Adjusted EBITDA; financing, taxes, and working capital are simplified. AI assistance supported troubleshooting, presentation, and packaging.

The distributor dashboard is a historical research tool using public information. Screening flags identify questions for further investigation, not investment ratings. Data validation checks consistency with saved SEC observations.
